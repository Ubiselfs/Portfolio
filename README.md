# Peter Helou Portfolio

A modern, responsive personal portfolio website built with React, Vite, and Tailwind CSS.

This portfolio presents my background as a Computer Science student and UI/UX Website & Mobile App Developer. It includes sections for About, Resume, Portfolio, Blog, and Contact, with a clean dark theme, gold accent color, reusable components, responsive layouts, and a professional card-based design suitable for internship applications.

## Features

- Responsive dark-themed portfolio design
- Left profile sidebar on desktop
- Mobile-friendly stacked layout
- Smooth page transitions
- Active navigation states
- Resume timeline section
- Portfolio project cards
- Blog placeholder section
- Contact form using email draft submission
- Reusable React components
- Organized project data in a separate data file
- Ready for Vercel deployment

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
